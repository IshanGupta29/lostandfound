# 🌊 Campus Lost & Found

A full-stack mobile application built to help students easily report, search for, and claim lost items around campus. Built with **Flutter** for a premium, animated frontend and **Node.js/MongoDB** for a robust backend. 

Submitted for DEVSOC.

---

## ✨ Features

### 📱 Frontend (Flutter)
* **Secure Authentication:** Full login and registration system using token-based auth.
* **Premium UI/UX:** Custom "Deep Sea" glassmorphism theme with frosted glass effects.
* **Animated Interactions:** Tween animations, smooth page transitions, and a staggered cascading feed.
* **Live Feed:** View all lost and found items in a clean, scrollable list.
* **Advanced Search & Filter:** Instantly filter reports by "Lost" or "Found" and search by item title or description.
* **Full CRUD Capabilities:** 
  * Create new item reports.
  * Edit existing report details.
  * 1-Tap toggle to mark items as "Claimed/Resolved."

### ⚙️ Backend (Node.js & Express)
* **MVC Architecture:** Clean separation of Models, Controllers, and Routes.
* **MongoDB Integration:** Secure schema validation for user and item data.
* **Security:** `.env` protection for database credentials and JWT secrets.
* **RESTful API:** Efficient endpoints for handling client requests.

---

## 🛠️ Tech Stack

* **Frontend:** Flutter, Dart
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** JSON Web Tokens (JWT)

### Prerequisites
* [Flutter SDK](https://docs.flutter.dev/get-started/install) installed.
